# 🚀 Deployment Instructions for Alem Asefa Counseling Website

## Quick GitHub Pages Deployment

### Step 1: Create GitHub Repository
1. Go to https://github.com/
2. Sign up/Login
3. Click "New repository"
4. Name: `amracounseling`
5. Make it **Public**
6. Check "Add a README file"
7. Click "Create repository"

### Step 2: Upload Files
1. In your new repository, click "uploading an existing file"
2. Drag and drop ALL files from the `dist` folder:
   - `index.html`
   - `favicon.svg` 
   - `vite.svg`
   - `assets` folder (with all contents)

### Step 3: Enable GitHub Pages
1. Go to repository **Settings**
2. Scroll down to **Pages** section
3. Source: **Deploy from a branch**
4. Branch: **main** 
5. Folder: **/ (root)**
6. Click **Save**

### Step 4: Get Your Live URL
- Your website will be available at:
- `https://[your-username].github.io/amracounseling`
- Takes 2-5 minutes to go live

## Alternative: Netlify (Even Easier)
1. Go to https://netlify.com/
2. Sign up
3. Drag the entire `dist` folder to Netlify
4. Get instant URL like: `https://amazing-name.netlify.app`
