# Alem Asefa Counseling Website

A professional, responsive counseling website built with React, TypeScript, and Tailwind CSS for Alem Asefa, Licensed Clinical Professional Counselor (MS, LCPC).

## 🌟 Features

- **Professional Design**: Calming, clean interface designed for mental health clients
- **Fully Responsive**: Mobile-first design that works on all devices
- **Accessibility**: Built with semantic HTML5 and ARIA labels for screen readers
- **Modern Tech Stack**: React 19 + TypeScript + Vite + Tailwind CSS
- **Fast Performance**: Optimized build with Vite for quick loading times
- **SEO Friendly**: Semantic structure and proper meta tags

## 🎨 Design System

### Color Palette

- **Primary**: Soft Teal (#6BB5B5) - Calming and professional
- **Secondary**: Warm Beige (#F9F5EF) - Comfortable and welcoming
- **Accent**: Calming Green (#7BAE7F) - Natural and healing
- **Text**: Charcoal Gray (#333333) - Easy to read
- **Background**: White (#FFFFFF) - Clean and minimal

### Typography

- **Primary Font**: Lato - Clean and professional
- **Fallbacks**: Open Sans, Poppins, system fonts

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd amracounseling
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open your browser to `http://localhost:5173`

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 📝 Development Guidelines

### Code Style

- Use TypeScript for all components
- Follow React functional component patterns
- Implement proper error boundaries
- Use semantic HTML elements
- Keep components under 150 lines

### Accessibility

- Include alt text for all images
- Use proper heading hierarchy
- Implement ARIA labels where needed
- Ensure keyboard navigation works
- Test with screen readers

### Performance

- Optimize images and assets
- Use React.memo for expensive components
- Implement proper loading states
- Minimize bundle size
